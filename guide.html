Bible Map Guide

성경 읽기·필사 지도 사용 안내

1. 시작하기 2. 지도 화면 살펴보기 3. 장(章) 체크하기 4. 권 전체 체크 · 설교 영상 5. 다른 기기에서 이어보기 · 초기화 6. 자주 묻는 질문

1시작하기

처음 접속하면 가장 먼저 보이는 로그인 화면입니다.

실제 로그인 화면

  1. 1이름을 입력합니다. (선택 사항)
  2. 2생일 4자리를 입력합니다. (예: 1월 1일 → 0101) — 이름을 적으면 필수
  3. 3먼저 기록할 활동을 고릅니다 — 읽기 또는 필사
  4. 4성경을 고릅니다 — 구약 또는 신약
  5. 5[시작]을 누르면 지도 화면으로 이동합니다
왜 이름과 생일이 필요한가요? 동명이인이 있어도 진도가 섞이지 않게 하는 구분 값입니다. 비밀번호가 아니며, 같은 값을 다시 입력하면 언제 어디서든 진도를 이어볼 수 있습니다.
이름 없이 시작하면? (둘러보기 모드) 지도는 구경할 수 있지만 체크한 내용이 저장되지 않습니다. 진도를 남기려면 반드시 이름을 입력해주세요.

2지도 화면 살펴보기

로그인 후 보이는 화면입니다. 실제 사용 화면입니다.

신약성경 읽기지도 예시

  • 저장 중… / 저장됨 — 왼쪽 위 표시. 체크한 내용이 서버에 잘 전달됐는지 알려줍니다
  • 구약 바로가기 · 도움말 · 처음화면으로 — 오른쪽 위 링크 3개. 지금 보고 있는 성경의 반대쪽으로 바로 이동하거나, 이 도움말을 열거나, 로그인 화면으로 돌아갑니다
  • 통계 카드 4개 — 전체 진도(%), 완료한 장, 전체 장 수, 연결된 설교 편수
  • 범례 — 각 색상이 무엇을 뜻하는지 설명
  • 책 목록 — 소분류(사복음서·사도행전 / 바울서신 등)로 묶여서 권별로 나열

3장(章) 체크하기

각 권 카드 안의 숫자 칸을 눌러 진도를 표시합니다.

읽기와 필사는 서로 완전히 독립적입니다 "읽기지도"에서 장을 누르면 읽기 상태만 바뀌고, 필사 기록에는 전혀 영향을 주지 않습니다.
읽기완료 — 읽기지도에서 진하게 채워진 칸
필사만 완료 — 옅은 테두리로만 표시
둘 다 완료 — 읽기와 필사를 모두 마친 장
점 표시 — 그 장에 연결된 설교가 있다는 뜻

필사지도로 들어가면 색이 반대로 — 필사완료가 골드로 진하게 채워집니다

필사지도에서는 필사완료가 진하게, 읽기만 완료는 옅은 테두리로 표시됩니다. 읽기지도와 정반대입니다.

4권 전체 체크 · 설교 영상

한 권을 처음부터 끝까지 다 읽었다면 장을 하나씩 누를 필요가 없습니다.

  1. 1권 이름 바로 옆의 작은 체크박스를 누릅니다
  2. 2그 권의 모든 장이 지금 활동 기준으로 한번에 완료 처리됩니다
  3. 3다시 누르면 그 활동만 전체 초기화됩니다 (반대 활동은 유지)

각 권 카드 아래쪽엔 그 권과 관련된 설교 목록이 나옵니다 (위 스크린샷에도 보입니다).

  • 제목 왼쪽 배지(예: "5장")는 그 설교가 다루는 본문 범위입니다
  • 제목 오른쪽에는 설교자 이름이 표시됩니다
  • 목록을 누르면 해당 유튜브 설교 영상으로 바로 이동합니다

5다른 기기에서 이어보기 · 초기화

같은 주소로 접속해서 똑같은 이름과 생일을 입력하기만 하면 됩니다. 진도는 기기가 아니라 이름+생일 기준으로 저장됩니다.
주의 이름·생일을 하나라도 다르게 입력하면 새로운 사람으로 인식되어 진도가 안 보입니다.

화면 맨 아래 [진도 초기화] 버튼을 누르면 지금 보고 있는 활동의 진도가 전부 지워집니다.

되돌릴 수 없습니다 초기화 전에 확인 창이 한 번 더 뜨니, 정말 지우려는 게 맞는지 확인하고 눌러주세요. 반대쪽 활동 기록은 영향받지 않습니다.

6자주 묻는 질문

Q.이름을 안 넣고 시작했는데 진도가 사라졌어요.
둘러보기 모드는 애초에 저장이 안 됩니다. [처음화면으로]에서 이름을 넣고 다시 시작해주세요.
Q.시편은 왜 "장"이 아니라 "편"이라고 나와요?
시편만 원래 "편"이라는 단위를 씁니다. 다른 성경은 전부 "장"으로 표시됩니다.
Q.화면 로딩이 조금 느린 것 같아요.
진도를 불러오는 동안 잠깐 지연이 있을 수 있습니다("불러오는 중…" 표시). 정상적인 지연이니 잠시 기다려주세요.
Q.예전에 필사했던 기록이 읽기 화면에서 옅게 보여요. 지워질까요?
아닙니다. 읽기 화면에서는 읽기만 조작되므로 필사 기록은 안전하게 유지됩니다.
만든이의 글

성경을 필사하다보면 정작 그 말씀이 품은 뜻을 놓칠 때가 많습니다.

지금 내가 어디를 지나고 있는지. 이 본문이 어떤 의미를 지니는지.

막막해지는 순간이 누구에게나 있을 것입니다.

그럴 때 그 말씀에 해당하는 예배의 설교가 지도(Map)가 되어

다시 우리가 가야 할 길을 인도해줄 수 있을 거라고 생각했습니다.
